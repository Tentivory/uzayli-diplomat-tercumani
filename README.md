# 🛸 UZAYLI DİPLOMAT TERCÜMANI

> **Dünya tarihinin en önemli yazılımı.**  
> Galaktik Konsey, Birleşmiş Milletler ve Eskişehir 4. Ağır Ceza Mahkemesi tarafından **resmen** tanınmıştır (tanınmamıştır).

---

## 📜 Bu Nedir?

Bu depo, insanlık ile uzaylı medeniyetler arasındaki **ilk resmi diplomatik iletişim kanalını** açmak amacıyla geliştirilmiştir.  
Artık "Merhaba, nasılsınız?" demek yerine, profesyonel bir şekilde **ZORP-PLÖK-XXX** diyebilirsiniz.

Program, mesajınızı ultra-gelişmiş bir algoritma ile uzaylı diline çevirir, ardından (gerçekçi bir şekilde) uzaylı elçiden cevap alır.  
Cevaplar %100 orijinaldir. (Rastgele seçilmiştir ama ruhen orijinaldir.)

---

## 🚀 Kurulum ve Kullanım

```bash
# Klonele (eğer henüz etmediysen)
git clone https://github.com/Tentivory/uzayli-diplomat-tercumani.git
cd uzayli-diplomat-tercumani

# Çalıştır (Python 3.6+ gerekli, uzaylı işletim sistemi desteklenmez)
python3 uzayli_tercuman.py
```

Ardından mesajınızı yazın. Örnek:

```
🌍 İnsan mesajınızı yazın: Merhaba uzaylı kardeşler, barış istiyoruz
📤 Uzaylı diline çevrildi:
   ZORP-ahabrem-xxx GLOP-ılaüz-aaa ...
📥 Uzaylı Elçi'den gelen yanıt:
   ZORP-PLÖK: Anlaşıldı kardeş, galaktik barış anlaşması imzalandı. Ama önce çay ikram edin.
```

## 🧠 Teknik Özellikler

- **Gerçek zamanlı çeviri** (0.5 saniye gecikmeyle)
- **Galaktik frekans tarama animasyonu** (çok önemli)
- **8 farklı resmi uzaylı cevabı** (bilimsel olarak seçilmiştir)
- **Acil çıkış protokolü** (Ctrl+C ile)
- **Hiçbir dış bağımlılık yok** (sadece Python standart kütüphanesi ve hayal gücü)
